## Module Loop Prompt Shape

**REPO:** Hyper-Vibe-Coding-Course
**GOAL:** Build/rewrite [Module Name] following the 7-step teaching structure
**SUCCESS TEST:** Module renders in browser, all 7 sections present, no console errors, BROski XP claim works

### 7-Step Teaching Structure (mandatory for every module)
1. **STOP** — plain English context BEFORE any tech
2. **WHY** — real-world use case (Netflix / Uber / Stripe refs)
3. **HOW** — step-by-step with time estimates
4. **WIN** — clear, celebratable moment with explicit recognition
5. **NEXT** — warm bridge to next module
6. **HELP** — troubleshooting that normalises problems
7. **REWARD** — BROski XP claim trigger

### UX Rules (non-negotiable)
- Body text minimum 16px
- Line height 1.8 for long reads
- No sidebar during active lesson — full focus mode
- Always celebrate correct answers BEFORE any feedback
- No walls of text — chunk every 3 lines max
- Error copy: "Hmm, let's try that again" NOT "Error 400"
