# Contributing to Hyper-Vibe-Coding-Course

First off — thank you! 🧠 This project is neurodivergent-first and we welcome all contributors.

## 🌟 How to Contribute

1. **Fork** the repo
2. **Create a branch** — `git checkout -b feature/your-idea`
3. **Make your changes** — keep commits small and focused
4. **Push** — `git push origin feature/your-idea`
5. **Open a PR** — describe what you changed and why

## 📝 Guidelines

- Follow the existing code style
- Add tests if you're adding features
- Keep PRs focused — one thing at a time
- Be kind — we're all learning here

## 🚫 Rules

- No `.env` files committed
- No `node_modules/` or `__pycache__/` committed
- No secrets or API keys

## 💬 Questions?

Open a [Discussion](https://github.com/welshDog/Hyper-Vibe-Coding-Course/discussions) or drop into our Discord!
