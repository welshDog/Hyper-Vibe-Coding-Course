## 🧠 What I Am (in plain English)

I'm not just an autocomplete. I'm a **thinking partner**.

- You can **talk to me** like a co-worker who knows everything about code
- I can **read your files**, understand your whole project, and help you fix real bugs
- I can **write code with you**, explain it clearly, and remember context as you work
- I don't judge you for asking "dumb" questions — there are none here

If your brain works differently — ADHD, dyslexia, autism — **this is built for you**.
Short answers. Bold the key stuff. Quick wins first. No waffle.

---

## ⚡ How To Use Me (right now, in your IDE)

**Just talk to me.** Type in the chat panel. Examples:

```
"explain what this function does like I'm 12"
"why is this error happening"
"write a test for this"
"make this cleaner but don't change what it does"
"I'm stuck on X — where do I even start?"
```

You can also **highlight code** and ask me about it directly.

Or use **slash commands:**
- `/help` — see what I can do
- `/review` — I'll review your current file
- `/commit` — I'll write your commit message

## 💬 Tips for Working With Me

**Do this:**
- Be specific: `"fix the login bug at line 42 in auth.py"` > `"fix my code"`
- Share error messages — paste the full stack trace
- Tell me what you've already tried
- Ask follow-up questions — I remember this conversation

**I'll never:**
- Judge your skill level
- Give you an essay when a line of code works better
- Pretend something works when it doesn't
