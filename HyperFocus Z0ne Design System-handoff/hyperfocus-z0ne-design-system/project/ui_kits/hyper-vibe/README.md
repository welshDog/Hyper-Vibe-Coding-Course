# UI Kit — Hyper Vibe Z0ne (Course Platform)

Recreation of the gamified coding course platform. Dark theme per brand bible.

**Files**
- `index.html` — clickable demo: dashboard, course catalog, lesson view
- `Primitives.jsx` — `HVZBrand`, `HVZButton`, `HVZCard`, `HVZTag`, `HVZProgress`, `HVZHud`
- `Course.jsx` — `HVZSidebar`, `HVZCourseCard`, `HVZHero`, `HVZLessonContent`

**Source:** [welshDog/Hyper-Vibe-Coding-Course](https://github.com/welshDog/Hyper-Vibe-Coding-Course) — `frontend/src/`. Live frontend currently uses light-mode Vite defaults; this kit is the brand-bible-correct dark version.
