# UI Kit — BROski$Pets (Companion dNFTs)

Inventory + detail view for the gamified pet system. Reuses tokens from `colors_and_type.css` and HUD/progress primitives from `hyper-vibe/Primitives.jsx`.

**Files**
- `index.html` — pack inventory + detail panel + activity feed
- `Pets.jsx` — `PetSprite`, `PetCard`, `PetDetail`, `PetActivityRow`

**Stages:** EGG → HATCH → TRAINED → LEGENDARY · evolution chain visualized in detail card.
**Rarity:** common · rare · epic · legendary (holographic gradient ring).
