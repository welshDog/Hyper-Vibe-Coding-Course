# UI Kit — HyperCore (Agent Dashboard)

Multi-agent dashboard for the 29-container FastAPI/Docker platform. Dense data, neon glow only on status, terminal log stream on right rail.

**Files**
- `index.html` — agent overview + metrics + live log stream
- `Components.jsx` — `HCBrand`, `HCStatus`, `HCAgentCard`, `HCMetric`, `HCLogStream`, `HCSidebar`

**Source:** brand bible "Agent Dashboard" rules (high data density, glows reserved for status only, log stream always visible).
