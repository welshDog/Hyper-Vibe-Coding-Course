# Hyper-Vibe Operating Guide

## 1. Put sources in Drive
- Curriculum docs
- Transcripts
- Links
- Notes

## 2. Generate assets in NotebookLM
- Course outline
- Lesson plans
- Quiz packs
- Flashcards
- Slide decks
- Infographics
- Audio overviews
- Video overviews

## 3. Save outputs in the right folder
- 03_Visuals_SlideDecks
- 04_Infographics
- 05_Audio_Podcasts
- 06_Video_Overviews
- 07_Exports_Final

## 4. Use critique prompts
- Ask what is clear
- Ask what is confusing
- Ask what should be bigger
- Ask what to remove

## 5. Final pass
- Rename with the naming standard
- Move old versions to archive
- Keep the index updated
