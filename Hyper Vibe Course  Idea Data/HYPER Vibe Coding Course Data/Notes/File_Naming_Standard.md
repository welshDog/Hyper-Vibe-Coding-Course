# File Naming Standard

Use this pattern:

`HVBC_[type]_[module-or-topic]_v[version]`

Examples:
- HVBC_curriculum_master_v1
- HVBC_slide_deck_overview_v2
- HVBC_infographic_ecosystem_v3
- HVBC_audio_module1_v1
- HVBC_video_module5_v1

Rules:
- Keep names short.
- Use underscores, not spaces.
- Put final approved files in `07_Exports_Final`.
- Put old versions in `08_Archive`.
