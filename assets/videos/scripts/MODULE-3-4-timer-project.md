- Display font: Space Grotesk
- Body font: Inter

- I set minutes (1–60)
- Click Start → timer counts down
- Displays MM:SS in large neon text
- When done → screen flashes + plays a sound + shows "DONE. Ship it. 🚀"
- Pause and Reset buttons
