## 📖 SECTION 2 — Three Core Concepts (2:30 – 5:00)
### 🎬 SCREEN: Slide — "Events + State + Updates = Interactive"

---

To go from static to interactive you need three things.

[PAUSE]

### 🎬 SCREEN: "1. EVENTS" appears with example

One — EVENTS.

[PAUSE]

"When the user clicks — do something."
"When they type — respond."
"When they swipe — react."

[PAUSE]

Traditional coding: you'd write event listeners.
Vibe coding: "When they click the mood button, show them a message."

[PAUSE]

AI handles the technical part.
You describe the BEHAVIOUR.

[PAUSE]

### 🎬 SCREEN: "2. STATE" appears with example

Two — STATE.

[PAUSE]

Remember information about what the user did.

[PAUSE]

"They've clicked the happy button three times this week."
"Their current streak is five days."

[PAUSE]

No database needed yet.
We'll use browser memory — local storage.
It saves even if you refresh the page.

[PAUSE]

### 🎬 SCREEN: "3. UPDATES" appears with example

Three — UPDATES.

[PAUSE]

Change what's on screen based on state.

[PAUSE]

Show a total count.
Highlight the selected option.
Display a congratulations message.

[PAUSE]

All three together — that's interactive magic.

[PAUSE]
