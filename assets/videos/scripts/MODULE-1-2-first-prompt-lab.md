```
You are a creative web developer who loves bold, modern design.

I want to build a simple webpage that:
- Has a large title saying "Welcome to [YOUR NAME]'s Vibe"
- Shows a cool background (use gradient or color that surprises me)
- Has a button that says "Click for Vibes"
- When clicked, the button shows a random encouraging message
- Uses modern fonts (not Arial or Times New Roman)
- Works great on phone and desktop
- Has fun emojis scattered around

Build the complete HTML + CSS + JavaScript.
Give me the full code I can paste directly into my IDE.
Don't explain — just give the code block.
Make it FEEL good, not corporate.
```
