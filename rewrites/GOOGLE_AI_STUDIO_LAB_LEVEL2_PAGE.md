## 🔧 HOW — Your First Build in 4 Steps

**⏱️ Time: About 30 minutes**

**Step 1 — Open AI Studio Build Mode**
Go to [aistudio.google.com/vibe-code](https://aistudio.google.com/vibe-code)
Click **Build**.
You're in. No setup needed.

**Step 2 — Describe your idea**
Type exactly what you want in plain English.
Be specific about the look and the goal.

**Step 3 — Refine using chat**
Once the app appears, use follow-up prompts to tweak it.
Change colours, add features, adjust layouts — all by typing.

**Step 4 — Use Annotation Mode for visual fixes**
Click on any element on screen.
Describe what you want changed.
Gemini updates it live.

## 🔴 5 Beginner Mistakes to Avoid

1. **Trying to build everything in one prompt** — still the same rule as Claude. Build small, iterate.
2. **Ignoring Annotation Mode** — it's the secret weapon. Click first, type second.
3. **Forgetting to add System Instructions** — paste your coding standards and visual style once at the top so Gemini remembers them all session.
4. **Not connecting Firebase** — that's what makes this tool special. Don't skip it.
5. **Switching tools too early** — spend at least one full build here before moving to Trae.

## 🆘 HELP — If Things Break

**AI Studio breaks too. That's normal.**

Tell Gemini exactly what happened:

> "I expected X but got Y. Here is what I see on screen:"

Use Annotation Mode for visual bugs — click the broken element and describe the fix.

If the project feels big, ask:

> "Summarise the current project structure in plain English."

---

## 💡 Pro Tips — Level Up Faster

- Use **Voice Input** — click the mic and speak your prompt if typing feels slow.
- Use **System Instructions** — paste your visual style and standards once, and Gemini keeps them all session.
- Save your work using the **Save / Fork** option before big changes.
- Try asking: "Add a Framer Motion animation to the header" — one prompt, pro-level UI.
