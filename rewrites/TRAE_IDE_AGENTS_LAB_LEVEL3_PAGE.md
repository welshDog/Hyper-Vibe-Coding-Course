## 🔧 HOW — Your First SOLO Build in 4 Steps

**⏱️ Time: About 30 minutes**

**Step 1 — Download and set up Trae**
Go to [trae.ai](https://www.trae.ai) and download for Mac or Windows.
Open it. Pick your AI model. Claude 4 Sonnet or Gemini 2.5 Pro are the best starting choices.

**Step 2 — Open a new project and switch to SOLO Mode**
Create a new folder for your project.
Open Trae. Switch to **SOLO Mode** in the top panel.
SOLO Mode means Trae handles everything end to end.

**Step 3 — Describe your full project**
Be specific. Give it a goal, a visual style, and a list of features.
Trae will plan the architecture, write the code, and run previews automatically.

**Step 4 — Review, not rewrite**
Your job is now to **review the output** not fix every line.
Check the live preview in the built-in browser.
Ask Trae to change what doesn't look right using plain English.

## 🔴 5 Beginner Mistakes to Avoid

1. **Micromanaging SOLO Mode** — let it finish before you jump in. Trust the process.
2. **Skipping model selection** — Claude 4 Sonnet for reasoning, Gemini 2.5 Pro for speed. Pick intentionally.
3. **Not using the built-in browser** — this is your live preview. Use it before every review.
4. **Forgetting MCP connections** — link Supabase or your GitHub repo for real project power.
5. **Building too big too fast** — still the same rule. One feature at a time, even in SOLO Mode.

## 🆘 HELP — If Things Break

**SOLO Mode will occasionally go off track. That's normal.**

Tell Trae exactly what went wrong:

> "Stop. The layout is broken. Here is what I expected. Start over from the last working preview."

Use the **built-in browser** to screenshot the broken state and describe the fix.

If a feature is totally wrong, use the **rollback button** to undo all recent agent changes.
