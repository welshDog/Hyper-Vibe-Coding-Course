## 🔧 HOW — Your First Build in 4 Steps

**⏱️ Time: About 30 minutes**

**Step 1 — Set up your workspace**
Download VS Code and install the Claude extension.
That's your lab. You're ready.

**Step 2 — Describe your idea**
Use Plan Mode in Claude.
Write your idea as simple bullet points.
No code yet. Just the vision.

**Step 3 — Build one block at a time**
Use short prompts.
Build one feature at a time.
Don't try to build everything at once.

**Step 4 — Test after every change**
Run the app after every update.
If something breaks, it's easy to find.
If you skip this, it gets messy fast.

## 🔴 5 Beginner Mistakes to Avoid

1. **Pasting code you don't understand** — always ask Claude to explain it first.
2. **One-shotting a massive app** — build small, build iteratively, always.
3. **Vague prompts** — describe the final result, not a fuzzy idea.
4. **Doom scrolling while Claude thinks** — stay in flow, stay focused.
5. **Skipping tests** — test after every single change. Every. Single. One.
